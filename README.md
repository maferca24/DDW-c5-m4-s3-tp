# Trabajo Práctico - Sprint 3: La Tienda(C5-M4-S3-TP)

Trabajo Práctico - Sprint 3: Aplicación web interactiva para la gestión de productosSinTacc libres de gluten, desarrollada con React, Vite y Tailwind CSS, implementando persistencia local y soporte para modo oscuro mediante variables CSS personalizadas....


## Cómo correrlo
Asegúrate de tener Node.js instalado y ejecuta los siguientes comandos en tu terminal:

# Instalar dependencias
pnpm install

# Iniciar el servidor de desarrollo
pnpm run dev
